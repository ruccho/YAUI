# インストール

## 要件 {#requirements}

| | |
|---|---|
| Unity | **6000.3** (Unity 6.3) 以降 |
| レンダーパイプライン | Universal Render Pipeline (URP) 17.3 以降 |
| グラフィックス API | Vulkan、Metal、Direct3D 11 / 12。OpenGL ES はサポートしていません。 |

以下の依存パッケージは、YAUI と一緒に Package Manager がインストールします。

- Burst
- Collections
- Universal RP
- Unity UI (`com.unity.ugui`)。EventSystem のために使います

:::info
YAUI はテキストに Advanced Text Generator (ATG) を、Unity のバージョンごとに変わる内部 API を通じて使います。YAUI は起動時にそれを照合し、Unity 6.3 から 6.7 をサポートしています。Unity 6.3 から 6.5 では、テキストを変更するたびにアロケーションが起きます (テキストを文字列で渡し、リッチテキストをマネージドコードで解析するため)。

内部 API が一致しない Unity のバージョンでは、Unity 6.7 以降は機能の少ない公開のテキスト生成 API に切り替えます。それより前のバージョンには公開 API がないため、テキストは表示されません。
:::

## パッケージのインストール {#install-the-package}

**Window > Package Manager** を開き、**+** をクリックして **Install package from git URL...** を選び、次の URL を入力してください。

```
https://github.com/ruccho/YAUI.git?path=/Packages/com.ruccho.yaui#release
```

`Packages/manifest.json` に直接追加することもできます。

```json
{
  "dependencies": {
    "com.ruccho.yaui": "https://github.com/ruccho/YAUI.git?path=/Packages/com.ruccho.yaui#release"
  }
}
```

## 入力の設定 {#set-up-input}

YAUI はポインターとナビゲーションのイベントを EventSystem を通して受け取ります。シーンに EventSystem がなければ、**GameObject > UI > Event System** で追加してください。Input System UI Input Module と Standalone Input Module のどちらでも動作します。

次は[最初のパネルを作成](./quick-start.mdx)しましょう。
