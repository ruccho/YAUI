# サンプル

パッケージにはサンプルが含まれています。Package Manager の YAUI の **Samples** タブからインポートしてください。

| サンプル | 内容 |
|---|---|
| **Basic** | テキストと、EventSystem を使うボタンを持つパネル。ボタンは普通の `YauiElement` で、ポインターイベントに応じて色と大きさを変えるスクリプトが付いています。 |
| **Controls** | ボタン、トグル、トグルグループ、スライダー、入力欄、ドロップダウン、スクロールビュー。 |
| **Custom Shader** | `Yaui.hlsl` を使って作った、要素のためのカスタムマテリアル。[カスタムシェーダー](../manual/custom-shaders.mdx)を参照してください。 |
| **Particles** | `YauiParticle` で描く ParticleSystem。子要素の下、角丸のクリップの中、回転したマスクの中、YAUI のシェーダーでないシェーダーの例。[パーティクルとメッシュ](../manual/particles-and-meshes.mdx)を参照してください。 |
