# 制限事項

YAUI は高速であるために制約を選んでいます。その一部は uGUI と異なります。

- **URP のみ。** ビルトインレンダーパイプラインと HDRP はサポートしていません。
- **OpenGL ES は非対応。** YAUI は Vulkan、Metal、デスクトップのグラフィックス API をサポートします。
- **要素の Transform は無視されます。** 位置とサイズはレイアウトが決め、2D の描画変換がレイアウトの後に要素を動かします。3D には[ワールド空間のパネル](./panels.mdx#world-space)を使ってください。
- **uGUI と互換性がありません。** uGUI のコンポーネント (`Image`、`Text`、`LayoutGroup` など) は YAUI のパネルの中では動作せず、移行ツールもありません。uGUI のキャンバスと YAUI のパネルは同じシーンに共存できます。
- **ドローコールあたり最大 8 枚のテクスチャ。** それより多いとドローコールが分割されます。[画像](./images.mdx#textures-and-draw-calls)を参照してください。
- **`ClipChildren` は最も近い角丸のクリップだけを適用します。** より深い入れ子や他の形状には `YauiMask` を使ってください。マスクの縁はアンチエイリアスされません。
- **テキストは内部 API を使います。** Advanced Text Generator は内部 API を通して呼び出され、起動時に検証されます。Unity のバージョンと一致しない場合、テキストはメインスレッド上で公開 API の `TextGenerator` を使います (低速)。
- **スクロールビューは内容を仮想化しません。**
- **パーティクルとメッシュは 1 つずつドローコールになります。** YAUI のシェーダーでないマテリアルはクリップもマスクもされません。[パーティクルとメッシュ](./particles-and-meshes.mdx)を参照してください。
