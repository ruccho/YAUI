# Installation

## Requirements

| | |
|---|---|
| Unity | **6000.3** (Unity 6.3) or later |
| Render pipeline | Universal Render Pipeline (URP) 17.3 or later |
| Graphics API | Vulkan, Metal, Direct3D 11 / 12. OpenGL ES is not supported. |

The Package Manager installs these dependencies with YAUI:

- Burst
- Collections
- Universal RP
- Unity UI (`com.unity.ugui`), for the EventSystem

:::info
YAUI uses the Advanced Text Generator (ATG) for text, through internal APIs that change between Unity versions. YAUI checks them at startup and supports Unity 6.3 to 6.7. On Unity 6.3 to 6.5, changing a text allocates: the text is passed as a string, and rich text is parsed in managed code.

If the internal APIs of a Unity version do not match, Unity 6.7 and later fall back to the public text generator, which has fewer features. Earlier versions have no public text generator and show no text.
:::

## Install the package

Open **Window > Package Manager**, click **+**, choose **Install package from git URL...** and enter this URL:

```
https://github.com/ruccho/YAUI.git?path=/Packages/com.ruccho.yaui#release
```

You can also add it to `Packages/manifest.json` directly:

```json
{
  "dependencies": {
    "com.ruccho.yaui": "https://github.com/ruccho/YAUI.git?path=/Packages/com.ruccho.yaui#release"
  }
}
```

## Set up input

YAUI receives pointer and navigation events through the EventSystem. If the scene has no EventSystem, add one with **GameObject > UI > Event System**. Both the Input System UI Input Module and the Standalone Input Module work.
